# 정부 공고 API 연결 설정

현재 공고 목록은 중기부 RSS, 소진공 공식 사업공고 목록, 스마트공장 사업관리시스템 JSON과 기업마당의 공식 `지원사업정보 API`를 Sites 서버의 `/api/notices`에서 각각 호출하도록 구성되어 있습니다.

## 1. 기업마당 인증키 발급

1. 기업마당의 `정책정보 개방 > 지원사업정보 API` 화면을 엽니다.
2. `사용신청`에서 기관명, 신청자 정보, 시스템명과 운영 URL을 입력합니다.
3. 발급된 서비스 인증키를 복사합니다.

공식 신청 화면: <https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi>

## 2. Sites 서버 환경 변수

발급된 키는 HTML이나 `assets/js`에 저장하지 않고 Sites 서버 환경 변수에만 등록합니다.

- 변수명: `BIZINFO_API_KEY`
- 값: 기업마당에서 발급한 서비스 인증키

`server/index.js`는 각 공식 출처를 서로 독립적으로 조회합니다. 한 기관이 실패해도 정상 응답한 기관의 공고는 계속 전달합니다. 접수 종료일이 오늘보다 이전인 공고는 통합 목록에서 제외하며, 화면 새로고침과 사용자가 선택한 자동 갱신 시점에는 `/api/notices`를 다시 호출합니다.

## 3. 현재 분류 기준

- 기업마당: 공식 API가 제공한 접수 가능 공고
- 중기부: 공식 사업공고 RSS에 등록된 신규 공고
- 소진공: 공식 사업공고 목록에 표시된 접수 가능 공고
- 스마트공장: 공식 사업관리시스템에서 접수 상태가 `ING`인 공고

중기부 RSS에는 접수기간이 없기 때문에 기업마당의 같은 제목 공고가 있으면 접수기간과 함께 통합하고, 없으면 오늘 신규 공고에서 원문 링크와 등록일을 우선 제공합니다. 소진공 목록에는 등록일이 없어 오늘 신규 공고 판정에서는 제외하고 접수 가능 통합 목록에만 표시합니다.
