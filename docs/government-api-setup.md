# 정부 공고 API 연결 설정

현재 공고 목록은 공공데이터포털의 `중소기업 지원사업 공고 조회 서비스`를 Sites 서버의 `/api/notices`에서 호출하도록 구성되어 있습니다.

## 1. 공공데이터포털 인증키 발급

1. 공공데이터포털의 `중소기업 지원사업 공고 조회 서비스` 화면을 엽니다.
2. 활용 신청을 완료하고 일반 인증키를 발급받습니다.
3. 발급된 서비스 인증키를 복사합니다.

공식 서비스 화면: <https://www.data.go.kr/data/15157820/openapi.do>

## 2. Sites 서버 환경 변수

발급된 키는 HTML이나 `assets/js`에 저장하지 않고 Sites 서버 환경 변수에만 등록합니다.

- 변수명: `DATA_GO_KR_API_KEY`
- 값: 공공데이터포털에서 발급한 일반 인증키

`server/index.js`는 공공데이터포털 응답의 전체 페이지를 조회합니다. 접수 종료일이 오늘보다 이전이거나 접수기간을 확인할 수 없는 공고는 목록에서 제외하며, 동일한 `pblancId`는 수정일이 최신인 한 건만 전달합니다. 화면 새로고침은 `/api/notices?refresh=1`로 즉시 다시 수집하고, 자동 갱신 시점에는 `/api/notices`를 다시 호출합니다.
