# DX CORE 정부 지원사업 알리미 디자인 가이드

## 1. 디자인 목표

DX CORE 정부 지원사업 알리미는 제조업 대표가 관심 키워드에 맞는 정부지원사업을 빠르게 찾고, 컨설턴트가 고객 조건에 맞는 사업을 검색해 상담할 수 있도록 돕는 정보형 웹앱이다.

## 2. 디자인 방향

- 색: 신뢰감을 주는 네이비를 기본 색으로 사용하고, 검색 버튼과 링크에는 청록색, 접수 가능 상태에는 초록색, 마감 임박에는 빨간색을 사용한다.
- 여백: 첫 화면에서 서비스명, 관심 키워드 입력, 오늘 신규 공고, 검색 결과가 한눈에 보이도록 영역 사이를 분명히 나누되 과하게 넓은 여백은 쓰지 않는다.
- 순서: 사용자가 처음 들어오면 관심 키워드를 입력하거나 저장한 뒤 오늘 신규 공고, 조건에 맞는 통합 공고 목록과 상세 정보를 확인하도록 구성한다.
- 문구: 제조업 대표와 컨설턴트가 바로 이해할 수 있도록 "관심 키워드", "오늘 신규 공고", "접수 기간", "사업 보러가기"처럼 짧고 직접적인 표현을 사용한다.
- 계정: 상단 브랜드 영역에 로그인 상태를 표시하고, 로그인·회원가입은 별도 로그인 페이지에서 처리한다.

## 3. 색상

- 기본 색: `#0F2C59`
- 강조 색: `#176B87`
- 접수 가능: `#059669`
- 마감 임박: `#DC2626`
- 화면 배경: `#FFFFFF`
- 구분 배경: `#F8FAFC`
- 선 색: `#E2E8F0`

## 4. 글꼴

- 기본 글꼴은 `Pretendard`, `-apple-system`, `BlinkMacSystemFont`, `system-ui`, `sans-serif` 순서로 사용한다.
- 제목은 굵고 명확하게, 공고 목록과 상세 정보는 반복해서 읽기 편한 크기로 사용한다.

## 5. 첫 화면 구성

첫 화면에는 서비스명, 로그인 버튼, 관심 키워드 입력칸, 키워드 저장 버튼, 검색 버튼, 오늘 신규 공고 목록, 통합 공고 목록이 보여야 한다.

## 6. 핵심 화면 순서

1. 사용자는 첫 화면에서 관심 키워드를 입력하고 검색하거나 저장한다.
2. 사용자는 관심 키워드 영역 아래에서 오늘 신규 공고를 확인한다.
3. 화면에는 제목 또는 본문에 관심 키워드가 하나라도 포함된 사업만 통합 목록으로 보인다.
4. 사용자는 사업명을 눌러 해당 정부 공고 페이지로 이동한다.
5. 사용자가 로그인하면 계정에 저장된 관심 키워드로 목록을 다시 구성한다.

## 7. 공고 카드에 보여줄 정보

- 최종 사업 관리 정부 부처
- 사업명
- 실제 공고문 기준의 핵심 내용
- 사업 접수 기간
- 접수 사이트 또는 공고 페이지 이동 링크

## 8. 적용할 디자인 요소

- 높은 대비의 밝은 화면
- 상단 브랜드 영역
- 상단 메인 소개 영역의 네이비 배경 위에 `#00ffff` 빛줄기가 위 중앙에서 내려오는 마우스 반응형 배경 효과
- 상단 `DX CORE` 브랜드명은 React Bits TextLoop 기준의 흰색 물결 글자와 `#5227FF` 리본으로 반복 이동하고, 마우스를 올리면 일시 정지
- 관심 키워드 입력칸
- 키워드 저장 버튼
- 검색 버튼
- 오늘 신규 공고 영역
- 오늘 신규 공고와 마감되지 않은 전체 공고의 제목형 목록
- 각 목록의 페이지당 10개·20개·50개·100개 선택과 이전·다음 페이지 이동
- 공고가 없을 때 다시 검색할 수 있는 안내 문구
- 모바일에서도 한 열로 읽히는 반응형 화면
- 상단 로그인 버튼과 로그인 상태 표시
- 오늘 공고 요약의 전체·스마트공장·AI·AX·DX·R&D·정책자금·수출·기타를 누르면 선택 분류의 공고만 표시하는 분류 버튼
- 분류 버튼은 Animata Shift Tabs 기준으로 비선택 버튼을 가리키면 오른쪽 위 기준으로 살짝 기울고, 선택 버튼은 회전 없이 강조 테두리로 표시
- 분류 버튼의 이름 아래에는 Animata Reminder 기준의 구분선과 현재 접수 진행 중인 공고 숫자를 표시
- 이메일·비밀번호 로그인, 회원가입과 비밀번호 재설정 페이지
- 로그인한 사용자의 관심 키워드 계정 저장 상태 표시

### 로그인 디자인 기준

- 비로그인 상태에는 상단에 `로그인` 버튼을 표시한다.
- 상단 `로그인` 버튼을 누르면 별도 로그인 페이지로 이동한다.
- 로그인 페이지에는 이메일, 비밀번호, 제출 버튼과 짧은 오류 안내만 표시한다.
- 로그인과 회원가입, 비밀번호 재설정은 같은 로그인 페이지에서 처리한다.
- 로그인 전 임시 키워드는 계정에 합쳐지지 않는다는 안내를 로그인 페이지에 표시한다.
- 로그인 상태에는 이메일과 `로그아웃` 버튼을 표시한다.
- 모바일에서는 이메일과 버튼이 한 열로 배치되고 화면 밖으로 나가지 않게 한다.

## 9. 지금 하지 않을 디자인 요소

- 지역, 예산, 업력 등 세부 필터 사이드바
- 조회수 정렬
- 지원 캘린더
- Q&A 화면
- 전체 지원금 규모 대시보드
- 내 대시보드
- 화면 보조 토글
- 모바일 필터 서랍
