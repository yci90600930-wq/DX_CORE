# AI 개발팀 사용 안내

이 프로젝트에는 역할별 커스텀 Codex 에이전트 네 명이 설정되어 있습니다. 새 에이전트 설정은 Codex가 작업을 시작할 때 읽으므로, 설정 파일을 만든 뒤에는 이 프로젝트에서 새 작업을 시작해 사용합니다.

## 팀 구성

| 이름 | 역할 | 담당 범위 |
| --- | --- | --- |
| 짱구 | HTML 담당 | `index.html` 구조, 시맨틱 마크업, 폼과 접근성 |
| 철수 | CSS 담당 | `assets/css/styles.css`, 디자인과 모바일 반응형 |
| 훈이 | JS 담당 | `assets/js/`, 검색·필터·인증·상호작용 |
| 맹구 | QA 엔지니어 | 읽기 전용 기능·모바일·접근성·완료 기준 검증 |

## 바로 사용할 수 있는 호출 예시

- `짱구에게 로그인 영역의 HTML 구조를 점검하고 수정해줘.`
- `철수에게 휴대폰 폭에서 기관 버튼이 넘치지 않는지 확인하고 CSS를 수정해줘.`
- `훈이에게 기관별 공고 필터 동작을 수정해줘.`
- `맹구에게 현재 화면을 PRD 완료 기준과 모바일 기준으로 QA해줘.`
- `짱구, 철수, 훈이에게 담당 영역을 나눠 수정하게 하고 마지막에 맹구가 QA하도록 위임해줘.`

## 이름과 역할 확인 예시

- `짱구, 네 이름과 역할이 뭐야?` → `나는 HTML 담당 짱구야.`
- `철수, 네 이름과 역할이 뭐야?` → `나는 CSS 담당 철수야.`
- `훈이, 네 이름과 역할이 뭐야?` → `나는 JS 담당 훈이야.`
- `맹구, 네 이름과 역할이 뭐야?` → `나는 QA 엔지니어 맹구야.`

메인 에이전트는 요청의 주된 파일 영역을 판단해 담당자에게 위임하고, 여러 영역이 함께 바뀌면 파일 충돌이 없도록 작업을 나눕니다. 최종 통합과 사용자 보고는 메인 에이전트가 담당합니다.
