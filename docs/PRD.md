# 정부지원사업 검색 웹앱 PRD

## 1. 문서 개요

- **제품명:** DX CORE 정부 지원사업 알리미
- **개발 단계:** MVP
- **목적:** 제조업 대표가 관심 키워드에 맞는 정부지원사업을 한 화면에서 찾고, 컨설턴트가 고객이 원하는 사업을 쉽게 검색할 수 있는 웹앱을 만든다.

## 2. 기획 배경

제조업 대표는 연말에 다음 해 투자 계획을 세울 때 정부지원사업을 찾아야 하지만, 어떤 사이트에서 어떻게 검색해야 하는지와 어떤 사업이 자신에게 맞는지 알기 어렵다.

현재는 여러 정부지원사업 사이트에 각각 접속해 키워드로 검색하거나 알고 있는 공급기업에 문의하고 있다.

여러 사이트를 반복해서 확인해야 하는 불편을 줄이고, 고객과 컨설턴트가 필요한 공고를 한곳에서 확인할 수 있도록 한다.

## 3. 제품 정의

제조업 대표가 정부지원사업 정보와 컨설팅이 필요할 때 관심 키워드에 맞는 사업을 찾고, 컨설턴트가 고객이 원하는 정부지원사업을 검색하도록 돕는 웹앱이다.

## 4. 대상 사용자

### 제조업 대표

정부지원사업 정보를 찾고 있으며, 자신의 관심 키워드와 관련된 신규 공고와 접수 정보를 빠르게 확인하려는 사용자다.

### 컨설턴트

제조업 대표에게 정부지원사업 컨설팅을 제공하기 위해 고객이 원하는 사업을 쉽게 검색하려는 사용자다.

## 5. MVP 목표

사용자가 관심 키워드를 저장하거나 직접 검색해 관련 정부지원사업을 찾고, 실제 공고문과 접수 정보를 확인할 수 있게 한다.

## 6. MVP 핵심 기능

### 6.1 관심 키워드 저장

- 첫 화면에 관심 키워드 입력칸과 `저장` 버튼을 제공한다.
- 사용자가 여러 관심 키워드를 저장할 수 있게 한다.
- 로그인하지 않은 사용자의 관심 키워드는 현재 페이지 상태에서만 사용할 수 있도록 임시 저장한다.

### 6.2 오늘 신규 공고

- 첫 화면에 저장된 관심 키워드와 맞는 신규 정부지원사업만 보여준다.
- 신규 공고의 조회 기간은 사용자의 접속 시점을 기준으로 전날 00시부터 현재 접속 시간까지다.
- 공고 등록일은 공공데이터포털 응답의 `creatPnttm`을 기준으로 판단한다.
- 화면에 실제 조회 시작 시각과 종료 시각을 표시한다.
- 목록에는 공고 제목만 표시하고, 제목을 누르면 기존 내부 상세 화면으로 이동한다.
- 한 페이지에 10개, 20개, 50개 또는 100개를 표시하도록 선택하고 이전·다음 페이지로 이동할 수 있게 한다.

### 6.3 핵심 키워드 검색

- 첫 화면에 제목이나 본문에서 찾고 싶은 핵심 키워드를 입력하는 검색창과 `검색` 버튼을 제공한다.
- 저장하거나 검색한 키워드 중 하나라도 공고 제목 또는 본문에 포함되면 검색 결과에 표시한다.
- 첨부파일 내용은 검색 대상에 포함하지 않는다.

### 6.4 공고 통합 조회

- 공공데이터포털의 중소기업 지원사업 공고 조회 서비스를 서버에서 호출해 공고를 가져온다.
- 공공데이터포털 인증키는 브라우저에 노출하지 않고 서버 환경 변수 `DATA_GO_KR_API_KEY`로만 관리한다.
- 매 페이지 방문마다 상류 API 전체를 호출하지 않도록 서버에서 5분 동안 최근 정상 응답을 재사용한다.
- 사용자가 전체, 스마트공장, AI·AX, DX, R&D, 정책자금, 수출, 기타 분류를 누르면 해당 공고만 오늘 신규 공고와 전체 공고 목록에 표시한다.
- 각 분류명 아래에 현재 접수 진행 중인 공고 수를 표시한다.
- `전체`를 누르면 모든 분류의 공고를 표시한다.
- 사용자가 공고 갱신 주기를 30분 단위로 설정할 수 있게 한다.
- 새로고침이나 사용자의 공고 갱신은 서버가 공공데이터포털 API를 다시 호출하도록 한다.
- 마감되지 않은 전체 공고 목록에는 공고 제목만 표시한다.
- 기존 화면 분류는 유지하고, 각 공고에는 공고명·사업개요·해시태그·소관기관에서 확인한 지역을 별도 표시한다.
- 특정 지역을 확인할 수 없으면 `전국`으로 표시하고, 여러 지역이 명시되면 해당 지역을 함께 표시한다.
- 기존 화면 분류 아래에 `지역 전체`, `전국`과 17개 시도별 공고 수를 표시하는 지역 버튼을 제공한다.
- 지역 버튼을 누르면 기존 화면 분류 조건과 함께 적용해 오늘 신규 공고와 마감되지 않은 전체 공고를 거른다.
- 전체 공고 목록도 한 페이지에 10개, 20개, 50개 또는 100개를 표시하도록 선택하고 이전·다음 페이지로 이동할 수 있게 한다.

### 6.5 중복 공고 통합

- 공공데이터포털의 `pblancId`가 같으면 동일한 공고로 판단한다.
- 같은 공고 ID가 여러 번 반환되면 수정일이 가장 최신인 공고 하나만 보여준다.

### 6.6 공고 상세 확인

- 통합 공고의 출처는 해당 사업을 최종 관리하는 정부 부처로 표시한다.
- 사용자가 검색 결과의 사업을 누르면 해당 공고 페이지로 이동할 수 있게 한다.
- 해당 공고 페이지에서 실제 공고문, 사업 접수 기간과 접수 사이트를 확인할 수 있게 한다.

### 6.7 사용자 로그인과 관심 키워드 영구 저장

- 사용자가 이메일과 비밀번호로 회원가입하고 로그인할 수 있게 한다.
- 로그인한 사용자의 관심 키워드는 사용자 계정에 저장하고 다시 접속했을 때 불러온다.
- 비로그인 사용자의 관심 키워드는 기존처럼 현재 페이지 상태에서만 임시 저장한다.
- 로그인 전 임시 저장한 관심 키워드는 로그인한 계정에 합치지 않는다.
- 로그인 성공 시 계정에 저장된 관심 키워드만 표시한다.
- 첫 화면의 `로그인` 버튼을 누르면 별도 로그인 페이지로 이동한다.
- 로그인 페이지 한 곳에서 로그인, 회원가입과 비밀번호 재설정을 처리한다.
- 사용자가 로그아웃하거나 비밀번호 재설정 이메일을 요청할 수 있게 한다.

## 7. 사용자 이용 순서

1. 사용자가 페이지를 열면 관심 키워드 입력칸, 저장 버튼과 검색창이 오늘 신규 공고보다 먼저 보이고, 그 아래에 관심 키워드에 맞는 오늘 신규 공고가 보인다.
2. 사용자가 관심 키워드를 입력하고 `저장`을 누르면 현재 페이지에 임시 저장되며, 해당 키워드에 맞는 오늘 신규 공고만 보인다.
3. 사용자가 검색창에 제목이나 본문에서 찾고 싶은 핵심 키워드를 입력하고 `검색`을 누르면 키워드가 하나라도 포함된 공고가 보인다.
4. 사용자가 원하는 공고를 누르면 해당 공고 페이지로 이동하고, 실제 공고문, 접수 기간과 접수 사이트가 보인다.
5. 사용자가 로그인하면 계정에 저장된 관심 키워드를 불러오고, 이후 추가하거나 삭제한 키워드를 계정에 반영한다.
6. 사용자가 상단 `로그인`을 누르면 별도 로그인 페이지로 이동하고, 로그인에 성공하면 첫 화면으로 돌아온다.

## 8. 화면 구성

### 첫 화면

- 별도 로그인 페이지로 이동하는 `로그인` 버튼
- 관심 키워드 입력칸
- 관심 키워드 저장 버튼
- 30분 단위의 공고 갱신 주기 선택란
- 핵심 키워드 검색창과 검색 버튼
- 전날 00시부터 현재 접속 시간까지의 조회 기간
- 관심 키워드에 맞는 오늘 신규 공고 목록
- 오늘 신규 공고 페이지당 표시 개수와 이전·다음 페이지 이동

### 검색 결과 화면

- 입력한 핵심 키워드에 맞는 정부지원사업 목록
- 조건에 맞는 사업이 없을 때 결과가 없다는 안내
- 중복 공고가 통합된 하나의 검색 결과
- 마감되지 않은 전체 공고의 페이지당 표시 개수와 이전·다음 페이지 이동

### 공고 상세 화면

- 실제 공고문
- 사업 접수 기간
- 접수 사이트
- 해당 사업을 최종 관리하는 정부 부처
- 사업을 눌렀을 때 이동할 해당 공고 페이지

### 별도 로그인 화면

- 이메일 입력칸
- 비밀번호 입력칸
- 로그인과 회원가입 버튼
- 비밀번호 재설정 요청
- 새 비밀번호 저장
- 공고 화면으로 돌아가기
- 이메일 확인, 로그인 실패와 설정 오류 안내

## 9. 검색 및 표시 규칙

1. 여러 관심 키워드는 `모두 포함`이 아닌 `하나 이상 포함` 기준으로 검색한다.
2. 키워드는 공고 제목과 본문에서 검색한다.
3. 첨부파일 내용은 검색하지 않는다.
4. 공고 ID가 같으면 수정일이 최신인 하나의 결과로 표시한다.
5. 공고명, 사업개요와 해시태그를 기준으로 화면 분류를 결정한다.
6. 신규 공고는 전날 00시부터 현재 접속 시간까지 등록된 공고로 판단한다.
7. 공고 등록일은 공공데이터포털 응답의 `creatPnttm`을 기준으로 한다.

## 10. MVP 제외 범위

- 컨설팅 요청 기능
- 매일 아침 관심 공고 알림 기능
- 관심 사업 저장 기능
- 제조업 대표의 기업 조건 입력 기능
- 컨설턴트 전용 고객 요청 검색 기능
- 동일 사업의 과거 공고 비교 기능
- 사업 핵심 내용 정리 기능
- 첨부파일 내용 검색 기능

## 11. 완료 기준

- 로그인하지 않은 사용자가 첫 화면에서 관심 키워드를 현재 페이지 상태에 임시 저장할 수 있다.
- 저장된 관심 키워드에 맞는 오늘 신규 공고만 첫 화면에 표시된다.
- 사용자가 검색창에 핵심 키워드를 입력해 공고 제목 또는 본문에 키워드가 하나라도 포함된 사업을 찾을 수 있다.
- 공공데이터포털 공식 API의 공고가 검색 결과에 표시된다.
- 사용자가 화면 분류를 선택해 해당 분류 공고만 확인하고 `전체`로 돌아갈 수 있다.
- 각 분류 선택 버튼에서 현재 접수 진행 중인 공고 수를 확인할 수 있다.
- 사용자가 공고 갱신 주기를 30분 단위로 설정할 수 있다.
- 공고 ID가 같은 공고는 수정일이 최신인 하나의 결과로 표시된다.
- 통합 공고의 출처가 해당 사업을 최종 관리하는 정부 부처로 표시된다.
- 사용자가 결과를 눌러 해당 공고 페이지로 이동하고 실제 공고문, 접수 기간과 접수 사이트를 확인할 수 있다.
- 첨부파일 내용은 검색 결과를 결정하는 데 사용하지 않는다.
- 사용자가 이메일과 비밀번호로 회원가입, 로그인과 로그아웃을 할 수 있다.
- 기존 로그인 대화상자 대신 별도 로그인 페이지에서 로그인, 회원가입과 비밀번호 재설정을 할 수 있다.
- 로그인한 사용자의 관심 키워드가 계정별로 저장되고 새로고침 후에도 유지된다.
- 다른 사용자의 관심 키워드를 조회하거나 변경할 수 없다.
- 로그인 전 임시 키워드는 로그인한 계정에 합쳐지지 않는다.
- 사용자가 비밀번호 재설정 이메일을 요청할 수 있다.
- 오늘 신규 공고와 마감되지 않은 전체 공고가 제목만 있는 목록으로 표시된다.
- 두 목록에서 각각 페이지당 10개, 20개, 50개 또는 100개를 선택하고 이전·다음 페이지로 이동할 수 있다.
- 기존 화면 분류를 바꾸지 않고 제목 목록과 상세 화면에서 공고의 지역을 확인할 수 있다.
- 사용자가 별도 지역 버튼에서 지역별 공고 수를 확인하고 기존 화면 분류와 조합해 공고를 찾을 수 있다.

## 12. 예상 문제와 대응 기준

- 키워드가 하나만 포함되어도 검색되므로 관련성이 낮은 공고가 함께 나올 수 있다.
- 공고문과 사용자가 다른 표현을 사용하면 필요한 공고가 검색되지 않을 수 있다.
- 핵심 내용이 첨부파일에만 있으면 해당 내용은 검색되지 않는다.
- 공공데이터포털의 업데이트나 수집 지연으로 신규 공고가 누락될 수 있다.
- 공고의 분류 키워드가 부족하면 `기타`로 표시될 수 있다.
- 접수 정보가 변경될 수 있으므로 사용자가 원문을 확인할 수 있게 한다.

## 13. 추후 계획

### 컨설팅 연결

- 제조업 대표가 확인한 사업에 대해 컨설팅을 요청하는 기능을 추가한다.
- 컨설턴트가 고객의 조건에 맞는 사업을 검색해 상담하는 전용 기능을 추가한다.

### 개인화와 알림

- 매일 아침 관심 키워드에 맞는 신규 공고 알림을 받는 기능을 추가한다.
- 제조업 대표가 자신의 기업 조건을 입력하고 저장하는 기능을 추가한다.
- 관심 있는 정부지원사업을 저장하고 다시 확인하는 기능을 추가한다.

### 사업 분석

- 동일 사업의 최근 3년 공고를 비교해 달라진 내용을 보여준다.
- 정부지원사업의 핵심 내용을 정리해서 보여준다.
- 비교 항목은 총사업비, 사업 기간, 지원금액과 비율, 핵심 내용으로 한다.
- 사업 주관사와 사업명이 각각 90% 이상 일치하면 연도별 동일 사업으로 판단한다.

## 14. 연도별 동일 사업 판단 기준

사업 주관사와 사업명이 각각 90% 이상 일치하면 연도별 동일 사업으로 판단한다.
