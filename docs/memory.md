- React Bits의 공식 LightRays JS-CSS registry와 원본 WebGL 셰이더를 기준으로 메인 소개 영역에 빛줄기 배경을 추가했습니다.

- 600px 최소 높이와 반응형 레이아웃을 유지해 모바일에서도 본문과 버튼이 화면 밖으로 밀려나지 않도록 했습니다.
